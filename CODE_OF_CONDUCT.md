# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion about the work, and
no harassment of any kind.

Report unacceptable behavior privately to **devs@oim.media**. Reports are read
by the maintainers and kept confidential.
