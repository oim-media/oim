# Visual parity gate — design

Date: 2026-11-07 · Status: approved in conversation, pending written review

## Why

The conformance vectors check that a renderer **reads** a `.oim` correctly. They
do not check what it **paints**. On 2026-11-06 the Flutter SDK passed every vector
while drawing only the background of a library work. Five rules that decide the
picture lived only in the web player's code:

- the canvas background slot has z-index 0, wherever it is listed;
- a unitless `letterSpacing` is invalid CSS and is ignored;
- a background pattern uses the tile stored in the file (`svgRawXml`);
- a shape's shadow follows its silhouette (CSS `drop-shadow`) and goes under a picture fill;
- shapes are outlined with `stroke*`; there is no `border*` in the schema.

Each one was found by Josué comparing screenshots by eye. The gate makes this
comparison automatic and blocking, and makes it part of the **canonical contract**:
any renderer — ours or a third party's — can certify against it, not only Flutter.

## What it is

The web player is the reference renderer. Its rendering of each conformance vector
is published as a **golden image** in `@oim-media/spec`. A renderer conforms
visually when its rendering of every vector matches the golden under one metric,
implemented once, in a neutral tool.

Out of scope: the Tauri viewer (it embeds the web player), OVM video, animation
over time (everything is compared with animations off), interaction states.

## Pieces

### 1. Goldens — `packages/spec/vectors/golden/`

- `<vector>.web.png`, one per `vectors/<vector>.oim.png`.
- Rendering procedure (normative, written into `CANONICAL_SPEC.md`):
  width 800 CSS px, height from the canvas aspect ratio, device pixel ratio 1,
  animations disabled, default language of the file, default palette, base image
  shown, composited over opaque white `#FFFFFF`, after fonts and images have loaded.
- Generated by `packages/spec/tools/render-web-goldens.mjs`
  (`pnpm --filter @oim-media/spec goldens`): Playwright + Chromium, loading the
  built `packages/player-oim` bundle from a local static server.
- **Only regenerated on the WSL runner's Linux** (the CI environment). Fonts
  rasterise differently on Windows; goldens from Windows would fail every run.
- Published: `vectors` is already in the spec package's `files`.

### 2. Comparison tool — `packages/spec/tools/parity.mjs`

`node parity.mjs <renders-dir> --renderer <name> [--out <diff-dir>]`

- For each golden, reads `<renders-dir>/<vector>.png`. Missing file → failure.
- Zero dependencies: decodes PNG with `node:zlib` (8-bit RGB/RGBA, all five filter
  types; anything else → failure with the reason).
- Metric, per vector:
  1. Sizes must be equal, otherwise failure.
  2. A pixel differs when any channel differs by more than **40**/255.
  3. The difference mask is **eroded with a 3×3 kernel** (antialiasing and font
     hinting leave lines 1–2 px wide; a real defect is an area).
  4. Failure if the eroded mask covers more than **0.5 %** of the image, **or**
     if any 4-connected blob in it is larger than **24×24 px** (576 px) in area.
- Writes `<diff-dir>/<vector>.diff.png`: the golden dimmed to 30 %, eroded
  differences in red.
- Prints one line per vector (score, largest blob, verdict). Exit 1 on any failure
  that is not an expected exception.
- Exported in the package (`files` gains `tools/parity.mjs`; `tools/pack-contents.mjs`
  allows it).

### 3. Exceptions — `packages/spec/vectors/golden/exceptions.json`

```json
{ "flutter": { "<vector>": { "reason": "artistic-text not implemented", "since": "2026-11-07" } } }
```

- Per renderer: one renderer's gaps never hide another's.
- An excepted vector is still compared and reported, but does not fail.
- An excepted vector that **passes** fails the run ("remove the exception"), so
  the list cannot rot.

### 4. Flutter adapter — `sdks/flutter/test/visual_parity_test.dart`

- Runs only with `OIM_PARITY=1` (skips silently otherwise; the GitHub-hosted
  `flutter` job is unchanged).
- Renders every vector with `OimPlayer` under the same procedure as the goldens,
  wrapped in a white `ColoredBox`, and writes `build/parity/flutter/<vector>.png`.
  It does not compare: comparison is `parity.mjs`'s alone.

### 5. Web self-check

The same `render-web-goldens.mjs`, pointed at a temporary directory, followed by
`parity.mjs --renderer web`. It fails when the web player's painting changed
without regenerating the goldens, so goldens never go stale silently.

## CI — new job `parity` in `.github/workflows/ci.yml`

- `runs-on: vars.CI_RUNNER` (the WSL runner). A pull request from a fork **skips**
  the job: our machine never runs foreign code, and goldens are only valid there.
- Steps: checkout → pnpm/node setup → `pnpm install --frozen-lockfile` →
  `pnpm build` → web self-check → `setup-flutter` →
  `OIM_PARITY=1 flutter test test/visual_parity_test.dart` (in `sdks/flutter`) →
  `parity.mjs build/parity/flutter --renderer flutter` → on failure, upload the
  diff images as an artifact.
- One-time setup on the WSL runner, documented in the spec package README:
  `pnpm exec playwright install --with-deps chromium` (needs `sudo` for system
  libraries).
- `playwright` is a pinned exact devDependency of `@oim-media/spec`, at least two
  weeks old (`minimum-release-age`).

## Acceptance

The gate is accepted when, on the WSL runner:

1. It is **green** on `main` as of 1.27.5 (with exceptions recorded for known gaps).
2. It turns **red** for each of the five bugs of 2026-11-06, reintroduced one at a
   time in the Flutter SDK. If a threshold cannot do both, it is tuned and the
   measurement that justifies the value is written into `CANONICAL_SPEC.md`.
3. The web self-check turns red when a web-player paint change is made without
   regenerating the goldens.

## Edge cases

- **Vectors with no visible output** (pure metadata, e.g. accessibility): still
  compared; both sides paint the base image over white.
- **Signature-refused vectors**: the procedure renders what the player shows for
  them; a renderer that shows layers the web refuses fails, which is intended.
- **Fonts not embedded**: rendered with the platform fallback on both sides; the
  erosion and the blob limit absorb glyph differences, not a missing line of text.
- **New vector without a golden**: `parity.mjs` fails ("no golden for X") — the
  author must regenerate.
- **Golden without a vector**: failure ("orphan golden").
- **Runner offline**: the job queues, as `test` already does.

## Risks

- Chromium updates can shift antialiasing. Playwright is pinned; upgrading it means
  regenerating the goldens in the same PR.
- Golden images add to the package size: 34 vectors × ~50–150 KB. To be measured;
  if over 5 MB in total, compress with palette quantisation (lossless for the
  comparison is not needed, but quantisation must stay below the 40/255 tolerance).
